# Aula05-BackEnd
# 🚀 API - Barbearia Vintage Club

## 📌 Sobre o Projeto
Primeira programação utilizando o módulo Express do Node.js utilizando o tema hipotético de uma barbearia que solicitou as páginas "sobre" e "cortes", além da página inicial de Boas-vindas, no site fictício. 

## 🛠️ Tecnologias Utilizadas
- Node.js
- Express.js
- VsCode
- Thunder Client (para testes)

## 📡 Endpoints da API (Rotas)
| Método | Rota | Descrição |
| :--- | :--- | :--- |
| `GET` | `/` | Boas-vindas |
| `GET` | `/sobre` | Informações da barbearia |
| `GET` | `/cortes` | Lista todos os estilos de cortes, seus preços e o tempo em minutos para fazê-lo |

## 🧪 Como Rodar e Testar
1. Clone o repositório
2. Execute `npm install`
3. Inicie com `node server.js`
4. Teste as rotas no Thunder Client
